title: How Rad fits together
description: The few ideas worth knowing before you build with Rad.
---

Rad starts with your application's data model and keeps the database and
generated client aligned with it.

## The normal loop

```text
rad.schema.yaml
  -> rad schema migrate
  -> generated client
  -> application
```

You edit the schema, review the change, migrate the database, then use the
updated client. The database checks that a generated client belongs to the
schema version it connects to.
